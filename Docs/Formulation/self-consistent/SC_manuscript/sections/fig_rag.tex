% The reaction admissibility graph for the nine families. Drawn here rather
% than lifted from the mean-field treatment: that graph is a size-resolved
% ladder over four families, and this model carries moments over nine, with a
% basal chain and a grain-boundary loop channel the ladder has no vertex or
% edge for.
%
% EVERY EDGE IS CHECKED AGAINST THE SOLVER, not against the prose. An earlier
% version of this figure omitted the cascade sources of C_2i, C_3i and of the
% prismatic vacancy loops; the mobile clustering ladder and its dissociation
% edges; the homogeneous loop-nucleation channel that 2i+2i and i+3i feed; and
% the capture edges onto the basal family. Each appears in
% `rate_equations_core.h`, and each is now drawn.
%
% LAYOUT. Cascade production is drawn as a SOURCE STUB -- a short arrow with no
% origin vertex -- at each vertex it feeds, rather than as seven edges radiating
% from one node. Drawn the second way the source arcs sweep across the whole
% figure and cross every other edge; drawn this way the graph is planar apart
% from the reservoir edges on the right. The four mobile species are boxed so
% that capture onto a loop is one arrow per family: the growth law sums over all
% four with a sign set by polarity, so the bundle is faithful where twelve
% crossing arrows would be unreadable.

\caption{Reaction admissibility graph for the nine families of
\cref{eq:families}, carrying every edge class of \cref{tab:rag-processes}.
Cascade production is drawn as a short stub with no origin vertex at each
population it feeds, because it is a partition of one displacement rate rather
than a transfer between two populations: a part $G_m$ (P4) into each of the four
mobile species, and a part $J_k$ (P5) nucleating the prismatic loops of
\emph{both} characters and the basal family directly. The dashed stub onto $c_f$
becomes a stub onto $c_0$ when the basal chain is active, which it is not in
\cref{sec:results}. The four mobile species are boxed because capture onto a
loop sums over all of them (\cref{eq:growth}) with a sign set by whether the
species' polarity matches the family's, so one bundled arrow per family is
faithful where four would be unreadable. The interstitial prismatic family has a
second, homogeneous nucleation channel (P6) fed by $2i+2i$ and $i+3i$ reactions
among the mobile clusters, which is why the mobile ladder and the loop
populations are not separable even in principle. Dashed orange edges run
backwards to the mobile pool: dissociation of a small cluster (P3) and
peripheral emission from a vacancy loop (P8). The three prismatic variants of
each character are drawn as one vertex for legibility; they are separate
populations that exchange nothing with one another and differ only in habit
normal. The pyramid $c_0$ is not a loop --- it has no Burgers vector, no
perimeter and no coalescence channel, and enters only through a capture
cross-section.}
\label{fig:rag}
